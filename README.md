# HB Store Hub

HB Store Hub is an Android-based Shop & Storekeeper order management system.

## Features

### Shop
- Create and send orders
- Track order status
- View Pending / Checked / Completed orders
- View completed orders
- Cloud synchronization

### Storekeeper
- View orders from shops
- Checked / Pending / Packing workflow
- Start Packing before editing items
- Edit quantities during packing
- Mark items as Checked
- Mark items as Out of Stock
- Size-wise progress tracking
- Example: 8 of 10 completed
- WhatsApp order sharing
- Completed orders become View Only

### Order Workflow

New Order → Sent → Checked → Start Packing → Completed

### Shops
- Multiple shops supported
- Shop-wise order tracking
- Cloud-based order synchronization

## Technology

- Android
- Firebase
- Cloud Firestore
- Firebase Authentication
